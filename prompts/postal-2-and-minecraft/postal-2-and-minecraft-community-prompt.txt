I assume you want to be able to use the Character Controller from Postal 2 (Kicking, Shooting etc..) inside of Minecraft, You can achieve this by using a "passthrough" mod, which bridges both games, exports meshes from the Donor game, and uploads into the Host game. Both games can access each other's memory and the player's location is bridged between both worlds, The collision data from Minecraft is uploaded to Postal 2, and then the entity data is converted. You can mix-n-match what features you'd like, or how certain things are handled inside of each game, e.g, Minecraft entities use Postal 2 Entity types, or Minecraft entity types (remaining unchanged).

Here is a simple prompt I wrote that you can give to AI. keep in mind, you will need a fairly modern AI to be able to do this efficiently, older models can do it do (Sonnet 5, GPT 5.6, etc...) but they will achieve this slower and make more mistakes.

"I have created a folder, Inside that folder you should download a few things. (Linked at the end of this prompt.) The purpose of this project is to modify SkyCraft to work with Postal 2 and Minecraft, Minecraft should be the Host, and Postal 2 should be the companion. Postal 2's controls should be inside of Minecraft. I want you to create a markdown document, explaining the stages of this project, what the end result should be for this project, and information about the APIs or Functions from both games which are necessary to create this project. Create scripts which test each feature, e.g, passing through models from MC, passing information around both games, etc... These should be there to check if your code was written properly. Please do not use any form of a Computer-Use skill if you have an option to do that. Any testing that is different from those test scripts should be done by me. (In-game tests)
SkyCraft: https://github.com/chasmlol/SkyCraft/releases/tag/v0.1.0
Directory: <Replace with your Project Directory, I suggest having it on a disk with a large amount of storage>"
